# 논문 검색 및 수집 자동화 프로그램

## 1. 작업 목적

연구에 필요한 논문을 찾는 과정에서 검색어를 반복적으로 입력하고, 논문의 제목·DOI·발행연도·초록 등을 개별적으로 정리하는 데 많은 시간이 소요되었다.

이러한 반복 작업을 줄이기 위해 **검색어를 입력하면 관련 논문을 자동으로 검색하고 정보를 수집하는 프로그램**을 제작하였다.

## 2. 사용 도구 및 구현 내용

- **개발 도구:** Python 3.10
- **문헌 검색:** OpenAlex API
- **AI 모델:** Ollama `qwen3:14b`
- **검색 대상:** 상전이 물질 및 나노구조 관련 논문
- **수집 목표:** 논문 60편

OpenAlex API를 활용하여 논문을 검색하고, 제목·DOI·발행연도·초록 등의 정보를 자동으로 수집하도록 구성하였다.

수집된 논문은 DOI를 기준으로 중복을 제거하고 하나의 데이터 파일로 정리한다. 로컬 Qwen 모델은 수집된 논문의 초록을 바탕으로 관련성을 판단하는 보조 기능에 사용하였다

**검색 결과의 품질을 개선하기 위해 다음 두 가지 기능을 추가하였다.**

1. **인용수 기준 필터링:** 사용자가 최소 인용수를 지정하면 해당 기준 이상의 논문만 수집하도록 하였다.
2. **학술지 기준 필터링:** 사용자가 학술지 목록을 지정하면 해당 학술지에 게재된 논문만 수집하도록 하였다.

이를 통해 연구 목적에 따라 검색 범위를 조정하고, 불필요한 논문을 수동으로 선별하는 작업을 줄일 수 있도록 개선하였다.

## 3. 결과 확인 방법

검색 결과에서 다음 항목을 확인한다.

- 논문 제목, DOI, 발행연도, 초록이 정상적으로 수집되었는지
- 동일한 DOI를 가진 논문이 중복 저장되지 않았는지
- 입력한 검색어에 따라 실제 논문이 수집되는지
- 수집된 결과 파일을 정상적으로 열람할 수 있는지
- 최소 인용수 기준을 만족하지 않는 논문이 제외되는지
- 지정한 학술지 목록에 포함되지 않은 논문이 제외되는지

또한 **동일한 검색어에 대해 필터 적용 전후의 검색 결과를 비교**하여 추가한 기능이 의도한 대로 작동하는지 확인한다.

## 4. 한계 및 보완

초기 프로그램에서는 검색어를 기준으로 논문을 수집하기 때문에 **연구 목적과 직접적으로 관련이 없는 논문도 함께 검색되는 문제**가 있었다.

이를 보완하기 위해 **인용수 기준으로 수집 대상을 한정하거나 사용자가 제시한 학술지 목록에 게재된 자료만 수집하는 기능**을 추가하였다.

다만 인용수와 게재 학술지만으로 논문의 실제 연구 관련성을 완전히 판단할 수는 없다. 특히 발표된 지 얼마 되지 않아 인용수가 적은 중요한 논문이 제외될 가능성이 있으므로, 최종적인 문헌 선정에는 사용자의 검토가 필요하다.
