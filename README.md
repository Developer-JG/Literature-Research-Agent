# 논문 검색 및 수집 자동화 프로그램

## 1. 작업 목적

연구에 필요한 논문을 찾는 과정에서 검색어를 반복적으로 입력하고, 논문의 제목·DOI·발행연도·초록 등을 개별적으로 정리하는 데 많은 시간이 소요되었다.

이러한 반복 작업을 줄이기 위해 **검색어를 입력하면 관련 논문을 자동으로 검색하고 정보를 수집하는 프로그램**을 제작하였다.

## 2. 사용 도구 및 구현 내용

- **개발 도구:** Python 3.10
- **문헌 검색:** OpenAlex API
- **AI 모델:** Ollama `qwen3:14b`
- **검색 대상:** 상전이 물질 및 나노구조 관련 논문
- **수집 목표:** 논문 60편

OpenAlex API를 활용하여 논문을 검색하고, 제목·DOI·발행연도·초록 등의 정보를 자동으로 수집하도록 구성하였다.

수집된 논문은 DOI를 기준으로 중복을 제거하고 하나의 데이터 파일로 정리한다. 로컬 Qwen 모델은 수집된 논문의 초록을 바탕으로 관련성을 판단하는 보조 기능에 사용하였다.

## 3. 결과 확인 방법

검색 결과에서 다음 항목을 확인한다.

- 논문 제목, DOI, 발행연도, 초록이 정상적으로 수집되었는지
- 동일한 DOI를 가진 논문이 중복 저장되지 않았는지
- 입력한 검색어에 따라 실제 논문이 수집되는지
- 수집된 결과 파일을 정상적으로 열람할 수 있는지

## 4. 한계

검색어를 기준으로 논문을 수집하기 때문에 **연구 목적과 직접적으로 관련이 없는 논문도 함께 검색되는 문제**가 있었다.

따라서 수집된 논문 중 필요한 자료를 사용자가 다시 선별해야 한다는 한계가 남았다.
